## Security Note

Before uploading screenshots to GitHub, verify that they do not contain:

* Passwords
* Private SSH keys
* Access tokens
* Secret keys
* API keys
* Sensitive personal information
* Unnecessary public IP information

Screenshots should demonstrate the work without exposing credentials or secrets.
